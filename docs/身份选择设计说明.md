# 身份选择设计说明

> **设计原则**：身份选择不是独立页面，而是登录页的一个功能（弹窗/对话框）

---

## 🎯 设计决策

### ❌ 旧设计（独立页面）- 已废弃

```python
class LoginPage(BasePage):
    def login(self): ...

class IdentitySelectPage(BasePage):  # ❌ 独立页面
    def select_identity(self): ...
```

**问题**：
- ❌ 违背页面拆分标准
- ❌ 增加不必要的复杂度
- ❌ 测试代码需要切换多个页面对象

---

### ✅ 新设计（作为登录页方法）- 推荐

```python
class LoginPage(BasePage):
    def login(self): ...
    def select_identity_if_needed(self): ...  # ✅ 登录的后续动作
```

**优点**：
- ✅ 符合页面拆分标准
- ✅ 测试代码简洁
- ✅ 易于维护

---

## 📊 决策依据

### 应用页面拆分决策树

```
1. URL 不同？
   登录页：/dataapp/login
   身份选择：仍在 /dataapp/login（同一个页面）
   → ❌ 相同 → 继续

2. 功能不同？
   登录：验证用户名密码
   身份选择：选择角色（登录的后续步骤）
   → ❌ 属于同一个业务流程 → 继续

3. 元素不同？
   登录：输入框 + 按钮
   身份选择：身份按钮列表（弹窗形式）
   → ⚠️ 部分不同，但都是登录流程的一部分 → 继续

4. 需要独立测试？
   身份选择不能脱离登录独立测试
   → ❌ 不需要 → 合并

结论：✅ 不应该独立成页面，应该作为登录页的方法！
```

---

## 🎯 身份选择的本质

### 是一个"弹窗"（Dialog）

**特征**：
1. ✅ 没有独立 URL
2. ✅ 覆盖在当前页面上
3. ✅ 完成一个动作后消失
4. ✅ 不能独立存在

**类似场景**：
- 确认对话框
- 提示框
- 选择器
- 模态框

**设计模式**：
```python
class LoginPage(BasePage):
    # 主页面功能
    def login(self): ...
    
    # 弹窗功能
    def confirm_dialog_if_needed(self): ...
    def select_identity_if_needed(self): ...
```

## 🔧 使用方法

### 基础用法

```python
def test_login(login_page):
    # 打开登录页面
    login_page.open_login()
    
    # 执行登录
    login_page.login("T100002", "wisedu@1", "2222")
    
    # 选择身份（如果需要）
    login_page.select_identity_if_needed("信息中心管理员")
    
    # 验证登录成功
    assert login_page.is_logged_in()
```

---

### 参数化测试多个身份

```python
@pytest.mark.parametrize("identity", [
```

## 📝 API 文档

### `select_identity_if_needed(identity: str = None) -> bool`

**功能**：如果需要选择身份，则选择

**参数**：
- `identity` (str, optional): 身份名称
  - 传值：选择指定身份
  - 不传：选择第一个身份

**返回值**：
- `bool`: 是否成功选择

**示例**：
```python
# 选择指定身份
login_page.select_identity_if_needed("教师")

# 选择第一个身份
login_page.select_identity_if_needed()
```

---

### `is_identity_select_visible() -> bool`

**功能**：检查身份选择对话框是否显示

**返回值**：
- `bool`: 是否显示

**示例**：
```python
if login_page.is_identity_select_visible():
    print("需要选择身份")
    login_page.select_identity_if_needed("教师")
else:
    print("不需要选择身份")
```

---

### `get_available_identities() -> List[str]`

**功能**：获取所有可用身份列表

**返回值**：
- `List[str]`: 身份名称列表

**示例**：
```python
identities = login_page.get_available_identities()
print(f"可用身份：{identities}")
# 输出：可用身份：['信息中心管理员', '教师', '人事处管理员']
```

## 🎯 设计对比

### 场景：登录并选择身份

#### 旧设计（独立页面）❌

```python
def test_login():
    # 创建登录页面对象
    login_page = LoginPage(page)
    
    # 登录
    login_page.login("T100002", "wisedu@1", "2222")
    
    # 创建身份选择页面对象
    identity_page = IdentitySelectPage(page)
    
    # 选择身份
    identity_page.select_identity("教师")
    
    # 验证
    assert identity_page.is_logged_in()
```

**问题**：
- ❌ 需要创建两个页面对象
- ❌ 代码冗长
- ❌ 不符合业务直觉

---

#### 新设计（作为方法）✅

```python
def test_login():
    # 创建一个页面对象
    login_page = LoginPage(page)
    
    # 登录
    login_page.login("T100002", "wisedu@1", "2222")
    
    # 选择身份（同一个对象）
    login_page.select_identity_if_needed("教师")
    
    # 验证
    assert login_page.is_logged_in()
```

**优点**：
- ✅ 只需一个页面对象
- ✅ 代码简洁
- ✅ 符合业务直觉

## 🎯 总结

### 核心原则
1. **身份选择是弹窗，不是独立页面**
2. **作为登录页的方法，不是独立类**
3. **测试代码更简洁，维护更容易**

### 设计模式
```python
class LoginPage(BasePage):
    # 主功能
    def login(self): ...
    
    # 弹窗/对话框功能
    def dialog_action_if_needed(self): ...
```

### 适用范围
- ✅ 登录后的身份选择
- ✅ 确认对话框
- ✅ 提示框
- ✅ 其他弹窗场景

---

**这个设计更符合页面拆分标准，也更易于维护！** 🦐
