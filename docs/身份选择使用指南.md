# 身份选择使用指南

## 📋 背景

登录成功后，如果用户有多个身份，系统会显示**身份选择页面**，要求用户选择其中一个身份登录。

### 常见身份

- 信息中心管理员
- 教师
- 人事处管理员
- 教务处管理员
- 科研处管理员
- 研究生院管理员
- ...

---

## 🎯 使用场景

### 场景 1: 默认身份登录（信息中心管理员）

```python
def test_login_default(login_page):
    """使用默认身份登录"""
    
    login_page.open_login()
    login_page.login("T100002", "wisedu@1", "2222")
    
    # 如果需要选择身份，自动选择"信息中心管理员"
    if login_page.is_identity_select_page():
        login_page.select_identity("信息中心管理员")
    
    assert login_page.is_logged_in()
```

## 🔧 API 说明

### `is_identity_select_page()` - 检查是否需要选择身份

```python
if login_page.is_identity_select_page():
    print("需要选择身份")
else:
    print("不需要选择身份")
```

**返回值**: `bool`

---

### `select_identity(identity: str)` - 选择指定身份

```python
# 选择"教师"身份
login_page.select_identity("教师")

# 选择"信息中心管理员"身份
login_page.select_identity("信息中心管理员")
```

**参数**:
- `identity` (str): 身份名称，必须与页面上显示的完全一致

**返回值**:
- `bool`: 是否成功选择

**异常**:
- 如果找不到指定的身份，会抛出异常

---

### `get_available_identities()` - 获取所有可用身份

```python
identities = login_page.get_available_identities()
print(f"可用身份：{identities}")
# 输出：可用身份：['信息中心管理员', '教师', '人事处管理员', ...]
```

**返回值**:
- `List[str]`: 身份名称列表

### 示例 1: 基础用法

```python

from pages.common.login_page import LoginPage

    if login_page.is_identity_select_page():
        # 选择"教师"身份
        login_page.select_identity("教师")
    
    # 验证登录成功
    assert login_page.is_logged_in()
```

## ⚠️ 注意事项

### 1. 身份名称必须精确匹配

```python
# ✅ 正确
login_page.select_identity("信息中心管理员")

# ❌ 错误（名称不匹配）
login_page.select_identity("信息管理员")  # 缺少"中心"
login_page.select_identity("信息中心")     # 缺少"管理员"
```

---

### 2. 先检查是否需要选择身份

```python
# ✅ 推荐做法
if login_page.is_identity_select_page():
    login_page.select_identity("教师")

# ❌ 不推荐（可能报错）
login_page.select_identity("教师")  # 如果不需要选择身份，会报错
```

---

### 3. 等待页面跳转

```python
# 选择身份后，确保等待页面跳转
login_page.select_identity("教师")

# 验证登录成功（会自动等待页面跳转）
assert login_page.is_logged_in()
```

## 🐛 常见问题

### Q1: 如何知道有哪些可用身份？

**A**: 使用 `get_available_identities()` 方法：

```python
identities = login_page.get_available_identities()
print(f"可用身份：{identities}")
```

或者手动登录一次，查看页面上显示的身份选项。

---

### Q2: 身份选择失败怎么办？

**A**: 检查以下几点：
1. 身份名称是否完全匹配
2. 页面是否真的显示了身份选择
3. 查看日志和 Trace 了解详细错误

```python
try:
    login_page.select_identity("教师")
except Exception as e:
    print(f"选择身份失败：{e}")
    # 查看 Trace 了解详细信息
```

---

### Q3: 有些账号不需要选择身份怎么办？

**A**: 使用 `is_identity_select_page()` 检查：

```python
login_page.login("T100002", "wisedu@1", "2222")

if login_page.is_identity_select_page():
    # 需要选择身份
    login_page.select_identity("教师")
else:
    # 不需要选择身份，直接验证登录成功
    pass

assert login_page.is_logged_in()
```
